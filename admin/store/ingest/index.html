Paste supplier product URLs

One URL per line. Lines beginning with # are treated as comments. We currently have first-class adapters for poolpro.com.au, astralpool.com.au and waterco.com.au — anything else uses the generic JSON-LD / OpenGraph adapter.

1 · Save the manifest

Place the generated _ingest_queue.yaml at store/_ingest_queue.yaml in the repo.

2 · Run the ingest

python3 scripts/ingest_supplier.py --queue store/_ingest_queue.yaml

3 · Inspect & commit

Review store/_catalogue.yaml and the new files under store/product/<slug>/assets/. Commit and push — auto-SEO + sitemap regeneration happen as part of step 2.
