Public release notes

Security and privacy controls for a public store launch.

This brief explains the public-facing controls applied to the Palatial Pools website. It is deliberately high-level so visitors can understand the posture without exposing implementation details that would help an attacker.

Enabled

No live AI chatbot

The floating support widget no longer sends public chat messages to an AI endpoint. Visitors are routed to fixed tools, phone, email or Palatial Link.

Enabled

Security headers

Static deployment headers define a privacy-oriented content security policy, frame protections, MIME sniffing protection and conservative referrer policy.

Enabled

Public-safe sync

The asset sync manifest includes catalogue, document and seasonal service metadata only. It excludes customer records and staff-only operational data.

Enabled

Human-reviewed checkout

Store checkout sends a request for review. Payment is not taken in-browser, and stock, fitment and delivery are confirmed before money changes hands.

Publishing checklist

  • Public pages preserve stable URLs and sitemap entries.
  • Private paths remain blocked from indexing.
  • Node modules are ignored and not published.
  • Generated store pages remain static and crawlable.
  • PDF and HTML transparency documents are optional, not intrusive.
  • Photo and chemistry intelligence tools disclose privacy limits.
  • Predictive preloading respects reduced data modes and capped fetches.
  • No credentials, staff records or supplier secrets are stored in public files.

What a public visitor can expect

Pages should feel fast because likely next pages are warmed cautiously, product data is static, and large media remains lazy-loaded. Visitors are not tracked for behavioural profiling by this feature; browsing assistance is limited to current-page intent and anonymous seasonal context.

When an interaction could affect safety, money or property outcomes, the site nudges toward a human-reviewed path: water testing, fitment confirmation, service booking or quote approval.
